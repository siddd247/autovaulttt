Hardened Security Matrix

Built with Defense-in-Depth

Conceived as a B.Tech Cyber Security capstone, AutoVault implements fundamental enterprise defenses across every layer.

Cryptographic Hashing

Plaintext credentials are never committed to storage. Passwords are automatically salted and digested via Werkzeug's PBKDF2/scrypt key derivation.

IDOR Access Controls

All database lookups strictly enforce user tenancy. Cross-user parameter manipulation on object identifiers yields strict HTTP 403 Forbidden responses.

SQLi Immunity via ORM

Database queries operate via SQLAlchemy ORM with strictly parameterized queries, entirely preventing SQL injection attacks.

Anti-Enumeration Logic

Authentication failure handlers return uniform status responses to prevent hostile enumeration of registered usernames or emails.

Isolated Document Quarantining

Uploaded documents reside outside the public web root with strict extension whitelisting and authenticated gateway serving.

XSS Output Sanitization

All user-supplied inputs displayed in the interface are automatically HTML-escaped by Jinja2 to neutralize stored and reflected Cross-Site Scripting.
